# Early-Warning-System-Tanah-Longsor-Berbasis-Sensor-Tilt-Inclinometer-Cloud-Telemetry
Node ESP32 ditanam pada struktur pipa di lereng tanah, terhubung dengan MPU6050 dan Sensor Soil Moisture Kedalaman. ESP32 mengukur pergeseran kemiringan. Jika pergeseran sudut > 5° dari posisi awal, ESP32 memancar peringatan darurat ke Cloud Telemetry Server dan memicu buzzer sirene lokal.
